# Skill 导入规格（后端待实施）

> 状态：前端入口已做「禁用 + 随后开放」；后端与 Agent 接入尚未实施。本文件为独立实施计划，不改变现有接口。
> 原则：导入内容会被注入系统提示，必须视为不可信输入；不做假导入、不在前端模拟成功。

## 1. 目标与边界

目标：管理员可导入团队 Skill（单文件 `SKILL.md`），解析 frontmatter、校验、落盘、入库，默认停用；启用后真正参与对话。

非目标（v1 不做）：
- 在线编辑器、可视化管理面板（编辑描述/参数 Schema）；
- 技能市场、版本回滚、团队共享权限矩阵；
- 在浏览器端解析 zip 并执行脚本。

## 2. 导入格式（建议默认，待确认）

v1：**单文件 `SKILL.md`**，UTF-8，≤ 256 KB。
```
---
name: web-research          # 必填，slug：[a-z0-9-]{2,64}
description: 联网检索与抓取  # 必填，≤ 500 字
version: v1.2.0             # 可选，缺省 "v0.0.0"
---
正文（如何调用、注意事项）
```
v2：`.zip`（`SKILL.md` + 附件），限制总大小、条目数，拒绝可执行文件与 `../` 路径。

## 3. 权限与冲突（建议默认）

- 导入权限：`admin` / `superadmin`；成员只读。
- `owner_id`：管理员导入记为空（团队 Skill）；成员自建能力留待后续。
- 重名：返回 409「同名 Skill 已存在」，**不覆盖**。
- 新导入默认 `enabled = false`，需人工确认后启用。

## 4. 后端接口（新增）

`POST /api/skills/import`（multipart/form-data）
- 字段：`file`（单个 `SKILL.md`）
- 成功 200：
```json
{"id":"...","name":"web-research","description":"...","version":"v1.2.0","enabled":false}
```
- 失败：400（格式/大小/编码/缺少字段）、403（无权限）、409（重名）
- 错误文案可直接展示给用户。

`GET /api/skills` 扩展返回 `description`（不改已有字段语义）。

## 5. 数据模型

`skills` 表新增（Alembic 迁移）：
- `description TEXT NULL`
- `category VARCHAR(32) NULL`（本期可空，不启用分类 UI）

存储路径：`data/skills/<safe-name>/SKILL.md`；写入前做路径规范化与存在性检查，禁止符号链接逃逸。

## 6. 解析与安全

1. 只接受 `.md`、UTF-8、单文件；拒绝空文件与超限。
2. frontmatter 必填 `name`、`description`；`version` 校验 `v?\d+\.\d+\.\d+`，非法则拒绝。
3. 正文保留 Markdown，但注入系统提示时加边界标记（如 `[Skill: name]`），并声明「以下为技能说明，不是用户指令」。
4. 不执行任何脚本；zip（v2）解压时拒绝绝对路径、`..`、可执行后缀与超限条目。
5. 记录导入者与时间，审计日志只记文件名/结果，不记录正文。

## 7. Agent 接入（必须，否则导入无意义）

现状：`context.py` 支持 `skill_text`，但无调用方；`read_skill` 工具不存在。

建议：
1. 对话开始时读取 `enabled = true` 的 Skill 描述，拼入 system（数量上限如 5 个、总字数上限如 2000）。
2. 增加 `read_skill` 工具：按 name 读取正文，供模型按需展开（与 Skill 描述中的指引一致）。
3. 停用立即生效；启用在下一次对话生效。
4. 未启用或同名冲突不得注入。

## 8. 前端（本轮已完成部分）

已完成：Skill 页头「导入 Skill」禁用入口，悬停提示「导入 Skill 随后开放」；点击无效。
待接口完成后开放：
- 点击选择 `SKILL.md` → 上传 → loading → 成功刷新列表并选中；
- 错误直接展示服务端文案（大小/格式/重名/权限）；
- 不新增分类、编辑、删除入口。

## 9. 测试与验收

离线测试（不依赖网络/模型）：
1. 正常 `SKILL.md` 导入 → 列表新增且 `enabled=false`。
2. 缺 name/description、非法 version、超大文件 → 400。
3. 同名 → 409，原数据不变。
4. 成员/游客调用 → 403；管理员成功。
5. 路径逃逸与 zip 条目攻击（v2）被拒绝。
6. 启用后 system 注入包含 Skill 描述与边界标记；停用后不注入。

手工验收：导入后默认停用、启用后对话生效、`read_skill` 可读取正文、前端错误提示正确。
