# Stitch/Figma 设计资产分析（第二批：可渲染 HTML）

> 分析模式产物，未修改源代码。来源：13 个 HTML 设计稿 + 1 个运维日志附件（已排除）。
> 渲染核对：已用无头 Chrome 在 1440×1024 与 900×1024 实际渲染并截图。
> **定版决议（用户确认）**：以「Onefold 2.0」家族为视觉依据；公共文档不做收藏。

## 1. 资产总览

有效设计稿 13 份，分为两套设计家族：

### 家族 A「Onefold · 页面名（浅色/深色）」——功能与现有代码对应
| 页面 | 浅色 | 深色 | 说明 |
|---|---|---|---|
| 登录 | 注册、忘记密码 | ❌ | 缺登录页浅色与全部深色 |
| 后台 | 用户、用量 | ❌ | 缺无权限页与全部深色 |
| 知识库 | 个人、公共只读 | 个人深色 | 缺公共只读深色、空态 |
| Skill | ✅ | ❌ | 缺深色、空态 |
| 记忆 | ❌ | ❌ | 家族 A 未提供 |

### 家族 B「Onefold 2.0 · …」——**定版视觉依据**
- 工作区 Light/Dark（含导航、多 Agent、知识库检索状态、引用、延伸追问）
- 知识库 Light（三作用域、拖拽上传、索引流水线、文档详情侧栏）
- Skill 管理 Light（分类、创建、编辑、调用统计、参数 Schema）
- 研究记忆 Light（分类、记忆约束、提取来源、作用范围）
- 全部缺深色（除工作区）。
- **登录/后台没有 2.0 版本**，目前只有家族 A 画面。

## 2. 实际渲染后的设计规范（家族 A）

- 页面外壳：`min-h-[1024px] w-full overflow-y-auto px-32 py-24`；内容限宽 1100（后台/知识库）、860（Skill）、384（登录），纵向 gap 24。
- 字体：与项目一致（Inter / Noto Sans SC / IBM Plex Mono）；标题 headline-md；说明 body-sm 次要色。
- 无阴影、无渐变；卡片与表格容器圆角 8，描边 1px outline-variant。
- 页签（后台/知识库）：**下划线式**，`pb-8 border-b-2`，激活为 primary 描边 + on-surface 文字，未激活 outline 色。
- 登录页签：**胶囊分段控件**（rounded-full 容器，激活主色实心），与后台/知识库不同。
- 登录表单：字段可见 label + 占位示例；输入高 40px、圆角 8；主按钮高 40、整宽、圆角 6；卡片圆角 12、内边距 24。
- 后台表：表头 surface-container-low；角色显示为浅色徽章（管理员/成员/超管）；停用/撤销等操作为下划线文字链接（主色/错误色）；表格卡片圆角 8。
- 知识库表：状态与分块信息同行（`Ready 42 块 · 12 页`），失败错误同行红色；操作下划线；上传按钮为白底描边+图标。
- 公共只读：说明改为「公共知识库由管理员维护，普通用户只读。」，无上传按钮，行内仅「收藏」。
- 窄屏（<lg）：表格切换为卡片列表（`lg:hidden`），卡片含文件名、类型/状态/大小、操作；后台/知识库/Skill 均有此结构。

## 3. 与现有实现的可见差异

1. 页签：现为胶囊按钮（PillTabs），设计为下划线页签（后台/知识库）；登录设计为分段胶囊。
2. 登录表单：现仅有占位符；设计有字段 label 与示例占位，控件高度 40。
3. 表格：现容器圆角 12；设计为 8；角色现为纯文本，设计为徽章；操作颜色需按设计（主色/错误）。
4. 知识库：现状态分两行；设计同行；公共只读现在额外显示一段说明，设计合并进页头说明；设计新增公共文档「收藏」（后端不支持，见缺口）。
5. 窄屏：现表格横向滚动；设计为卡片列表。
6. 页面间距：现内容块间距 16；设计为 24。

## 4. 能力缺口（家族 A）

| 设计项 | 现状 | 结论 |
|---|---|---|
| 公共只读文档「收藏」 | `POST /documents/{id}/collect` 仅允许文档拥有者（`get_owned`），公共文档会 403/404 | **后端缺口**，需后端支持或本轮不实现 |
| 拖拽上传 | 现仅文件选择器；设计个人页未含拖拽（家族 B 才有） | 家族 A 无需实现 |
| 发布信息/已收藏态 | Doc 类型无字段 | 家族 A 未要求；家族 B 才涉及 |
| 「公共文档不可删除」 | 现非管理员本就无删除入口 | 现有权限已满足，无需改 |

## 5. 家族 B 的范围外能力

- 多 Agent 协同、知识库三作用域检索事件、引用页码/相关度、延伸追问、文档索引流水线、Skill 创建/编辑与调用统计、记忆约束分类与详情侧栏。
- 后端均无对应接口或事件；本轮不实施。

## 6. 仍缺的资料

1. 家族 B：知识库、Skill、研究记忆的深色画面。
2. 家族 B：登录、后台的对应设计（目前只有家族 A）。
3. 窄屏设计（2.0 三栏是否在 <1024 堆叠，需确认；当前 HTML 只给左导航 `w-full lg:w-[240px]` 的响应式提示）。
4. 交互状态（hover/focus/disabled）未单独给稿，按设计系统执行。

## 7. 2.0 定版后的能力缺口（阻断项）

| 2.0 设计能力 | 后端现状 | 结论 |
|---|---|---|
| 知识库三作用域（含临时文档列表/计数） | 无临时文档列表接口；个人/公共可列出 | 临时作用域无法真实展示 |
| 文档星标/已收藏 | 无收藏状态字段；收藏接口仅允许拥有者（公共文档 403） | 按用户决议：**不做收藏** |
| 发布人/发布时间 | Doc 无字段 | 不能显示，需省略 |
| 索引流水线时间/进度（如「14:04」） | status 有 parsing/ready/failed，无进度/时间 | 只显示真实状态 |
| 右侧文档详情（切片策略/权限说明） | chunk_count 有；策略文本可静态；选中态可用 | 部分可实现 |
| Skill 分类/创建/编辑/统计/Schema/授权角色 | 仅有列表(name/version/enabled)与启停 | 绝大部分阻断 |
| 记忆分类计数 | 可由 items 的 category 派生 | 可实现 |
| 添加记忆约束 / 每条启停 / 来源会话 / 团队共享 / 作用范围 | 接口无创建；无 per-item enabled；无 source/team 字段 | 阻断 |
| 工作区多 Agent/检索状态/引用/追问 | 无对应事件与工具 | 阻断（工作区改版另立项目） |
