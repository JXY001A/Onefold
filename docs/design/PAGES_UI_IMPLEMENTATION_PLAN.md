# 页面 UI 实施计划（Onefold 2.0 定版，待批准）

> 分析模式产物，未修改源代码。基线 HEAD `47fd34a`，工作树干净，`tsc`/`build` 通过。
> 用户定版：知识库 / Skill / 记忆以 **Onefold 2.0** 为视觉依据；登录 / 后台暂无 2.0 稿，按家族 A；**公共文档不收藏**。
> 状态：**阶段 1–6 已实施（2026-11-25）**。知识库、Skill、记忆、登录与后台已按定版落地；全量双主题/窄屏回归完成。上下文导航以页内页签替代。

## 0. 范围与边界

纳入：
1. 知识库、Skill、记忆：2.0 三栏结构（左 240 / 内容 820 / 右 320）与视觉。
2. 登录、后台：家族 A 视觉（无 2.0 稿）。
3. Light/Dark、<1024 堆叠、空/加载/错误态。

不纳入：
1. 2.0 工作区改版（多 Agent、检索状态、引用、追问）——另立项目。
2. 任何后端接口/字段/数据库变更。
3. 公共文档收藏（已决议不做）。

关键风险：2.0 三页的左侧上下文导航（知识库作用域/技能分类/记忆分类）在当前全局导航中不存在；右侧检查器无对应组件。需要新增共享壳，影响所有路由，必须单独验收。

## 1. 施工前仍需确认

1. 是否接受「视觉壳 + 真实数据 + 缺失能力省略/Soon」，而不是等待后端补齐后再施工？
2. 2.0 知识库/Skill/记忆的深色稿、登录/后台 2.0 稿是否补充？
3. 左侧上下文导航实现方式：
   - A（推荐）：路由感知的共享侧导航，在对应页面显示真实分组；缺失分类与临时文档不显示。
   - B：不改共享导航，省略分组（偏离 2.0 稿）。
4. 临时文档列表无接口：2.0 知识库「临时文档」分组与计数是否接受省略？
5. 窄屏：2.0 页面在 <1024 采用「导航→内容→右检查器」纵向堆叠，是否确认？

## 2. 阶段 1：2.0 页面壳与共享组件

- 目标：三栏壳（240/820/320）、路由感知上下文导航、右侧检查器骨架、下划线页签、卡片与列表基础样式。
- 文件：新增 `components/pages/PageWorkspace.tsx`（壳）、`components/pages/ContextNav.tsx`、`SideNav.tsx`（仅挂载上下文分组）、`ui/kit.tsx`（tabs 变体）、`ui/table.tsx`（圆角可配）。
- 禁止：改路由、权限、会话逻辑、工作区布局；不引入假数据。
- 依赖：第 1 节确认。
- 风险：共享导航影响工作区/其他页；必须全站回归。
- 步骤：壳 → 上下文导航（真实计数）→ 检查器骨架 → 组件变体。
- 验收：三页壳截图；工作区/其他页无视觉回归；窄屏堆叠。
- 回滚：新增文件删除 + 导航挂载回退。

## 3. 阶段 2：知识库（2.0）

- 目标：页头/上传/拖拽、范围分组、文档列表、右侧详情检查器。
- 文件：`pages/Documents.tsx`、`components/documents/DocTable.tsx`、新增 `components/documents/DocInspector.tsx`。
- 禁止：改上传/删除/重试/发布接口；不实现星标/收藏；不伪造发布时间、索引进度、临时文档。
- 依赖：阶段 1。
- 风险：列表字段与现有 Doc 类型对齐；拖拽上行沿用现有单文件接口。
- 步骤：页头/范围 → 列表真实字段 → 检查器 → 空/失败态。
- 验收：个人/公共、管理员/普通用户、拖拽上传、失败重试、浅色（深色待稿）、窄屏。
- 回滚：按文件回退。

## 4. 阶段 3：Skill（2.0）

- 目标：Skill 卡片/表格视觉；启用/停用真实可用；缺失能力克制处理；导入入口仅禁用提示。
- 文件：`pages/Skills.tsx`、`components/skills/SkillList.tsx`、`lib/skills.ts`。
- 禁止：不实现新建/编辑/删除/分类/调用统计/参数 Schema/授权角色（无接口）；不伪造字段；导入仅 Soon（见 SKILL_IMPORT_SPEC.md）。
- 依赖：阶段 1。
- 风险：2.0 稿大面积依赖不存在字段，需明确省略范围；避免空壳卡片。
- 步骤：真实列表 → 状态与启停 → 缺失项隐藏 → 检查器（仅真实字段或省略）。
- 验收：列表/启停/空态/浅色；无假统计；窄屏。
- 回滚：页面文件回退。

## 5. 阶段 4：记忆（2.0）

- 目标：分类计数（真实派生）、记忆卡片、右侧详情（真实字段）；全局启停/清空/编辑/删除保留。
- 文件：`pages/Memory.tsx`、`components/memory/MemoryCard.tsx`、新增 `components/memory/MemoryInspector.tsx`。
- 禁止：不实现「添加记忆约束」、每条启停、来源会话、团队共享、作用范围（无接口/字段）。

- 风险：分类来自后端中文值，可能为空（回退「其他」）；不能伪造团队共享。
- 步骤：分类派生 → 卡片 → 详情 → 空/失败态。
- 验收：分类计数正确、编辑/删除/清空、关闭横幅、浅色；无假来源；窄屏。
- 回滚：页面文件回退。
