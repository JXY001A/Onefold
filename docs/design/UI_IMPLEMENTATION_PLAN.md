- 阶段启动：1A 已获总方案授权；后续阶段在上一阶段验收通过后，按用户指定启动。
- 冲突规则：设计稿与现有业务冲突时**不得擅自改变业务行为**，先记录于 COMPONENT_MAPPING §7 并等待确认。
