# 落地页布局规范

> 基准：Figma 单帧 1440×3052。区块高度：Hero 712 / 能力区 1039 / 工作区 569 / 入口区 604 / 页脚 127。

## 0. 页面根

- 固定深色，不随主题切换；根节点挂 `landing-root` 作用域类。
- 全屏 fixed 环境底光层（`z-0`、`pointer-events-none`），内容层 `relative z-10`。
- `overflow-x-hidden`；页面无顶栏导航、无侧栏（脱离 App shell）。

## 1. 容器

- 主容器：`max-w-[1320px] mx-auto px-6 lg:px-12` → 1440 视口下内容宽 1224。
- 入口区容器：`max-w-[1120px]` → 内容宽 1024。
- 区块间分隔：`border-t border-white/[0.06]`；能力区叠加 `bg-cosmic-surface/40`，入口区叠加 `/50`。

## 2. Hero（1440×712）

- 12 栏网格：左 5 栏（文案，约 45%）/ 右 7 栏（canvas，约 55%），`gap-12 lg:gap-8`，垂直居中对齐。
- 左列自上而下：状态徽标胶囊（h≈31，圆角全、`card/80` 底、`primary/25` 描边、6px cyan 脉冲点 + mono 11px 大写眉题）→ H1（宽约 408）→ 引导语（max-w 500）→ 双 CTA 组（gap-4，水平排布）。
- CTA：主按钮 h-12 / min-w-184 / px-6；按钮上方文字，下方 12px 注释（max-w 220）。
- 右列：绝对定位体积光晕（340→480px 圆、72px 模糊、三色斜向渐变、呼吸动画）；canvas 容器 660×520（sm 高 460 / 基准高 520）。

## 3. 能力 Bento（1440×1039）

- 头部：眉题 + H2 + 引导语，左对齐，max-w 680，gap-3；与栅格间距 12（48px）。
- 栅格：12 栏、gap-6（24px）。模块 1（AI Research）7 栏=704 宽；模块 2（AI Agents）5 栏=496 宽；模块 3（AI Experiments）12 栏整行。卡片内边距 28（lg 32），模块 1/2 高 393，模块 3 高 226（左文 5 栏、右图 7 栏，垂直居中）。
- 卡片结构：顶行「mono 标签 + mono 序号」→ H3 → 描述（模块 3 为左列）→ 插图面板（h-180 / 模块 3 h-160，`bg-cosmic-bg/70`、`white/5%` 描边、圆角 12）。
- 插图：三张定制内联 SVG（viewBox 540×180 / 360×180 / 680×160），内容与配色按设计稿原样。

## 4. 工作区（1440×569）

- 12 栏：左 4 栏（眉题 + H2（28→36px）+ 引导语 + 三步列表），右 8 栏（截图卡）。
- 三步列表：每项 = 24×24 圆角块（mono 序号，三色交替 primary/purple/cyan 描边）+ 14px 文案，`gap-4`。
- 截图卡：外层 ambient 光晕（-inset-4、blur-2xl、三色 10–15%）；卡体圆角 16、`primary/25` 描边、`bg-cosmic-card`、大阴影；内部 img 宽 103%、四边 -1.5% 位移裁切。

## 5. 入口区（1440×604）

- 头部居中（max-w 780）：H2（30→40px）+ 一行引导语。
- 两卡并排（md 起 2 栏、gap-6）：各 500×235，p-8，内容纵向两端对齐；卡内 = mono 眉题（cyan / purple）+ H3 + 描述 + 按钮。主按钮卡用主按钮，个人卡用次按钮。

## 6. 页脚（1440×127）

- 主容器，`py-10`；移动端纵向、sm 起横向两端对齐。
- 左：品牌行（「Onefold · 归一」15px 600 + © 2026 12px muted）与一行 13px 描述。
- 右：三个 13px 链接（#capabilities / #workspace / 登录路由），hover 变为主文字色。

## 7. 响应式要点

- <lg：Hero、能力区、工作区一律单栏堆叠；canvas 高度 340（<sm）/ 460（sm–lg）。
- 能力区模块顺序：模块 1 → 模块 2 → 模块 3。
- 入口区 <md 单列。页脚 <sm 纵排。

## 8. 整屏翻页（用户要求的行为扩展，2026-11-28 批准）

> 此节不是设计稿内容，是用户在设计落地后的追加要求；与设计稿冲突处以本节为准。

- 页面由「五段内容流」改为 **4 屏**：Hero / 能力区 / 工作区 / 最后一屏（入口区 + 页脚贴底），每屏 `min-h-[100dvh]`，内容垂直居中。
- 桌面（精细指针 + 非 reduced-motion）：滚轮/键盘（PageUp/PageDown/方向键/Home/End）一次手势 = 800ms easeInOutCubic 缓动，精确过渡到相邻屏顶部；过渡期间锁定输入，结束后 250ms 防抖吸收触控板惯性。
- 超高屏规则：屏高超出视口 40px 以上时，先允许原生滚动阅读，到边界后再切换相邻屏；≤40px 的内边距级溢出按整屏切换。
- 触屏设备（`pointer: coarse`）与 `prefers-reduced-motion: reduce`：不做整屏吸附，退回原生滚动。
- 页脚锚点（#capabilities / #workspace）改为同样缓动定位。
- 能力区为塞进单屏做了纵向压缩（用户授权，2026-11-28 调整）：区块 `py-8 lg:py-10`、头部与栅格间距 32、卡片 `p-6 lg:p-7` 且内部 gap 16/20、插图面板 140/120、栅格 gap-5；**字号与结构不变**。§3 中的原始 1039px 尺寸仅作设计存档，不再作为实现基准。
- 修正（2026-11-28）：翻页接管时机改为屏边界上的**首个**滚轮事件即 preventDefault，避免原生滚动先漂移导致上行方向被误判为"超高屏内部"而失去吸附。
