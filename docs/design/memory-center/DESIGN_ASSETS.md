**C. 设计未定义**：亮色主题样式（已确认固定深色）；移动端专项布局；加载态/失败态/权限表现；"查看来源对话"跳转目标（真实产品需路由能力）。

**D. 无法确定**：无。

## 3. 关键结论

- 设计稿同时是**双词表**：布局与交互可直接落地；而数据层大量字段（引用/来源会话/停用状态/新增/导出）在后端不存在 → 按用户口径 mock 或敬请期待（见 COMPONENT_MAPPING.md）。
- 设计稿 Tailwind 配置把 `dark-*` 全部替换为宇宙蓝系（`dark-background #070B16`、`dark-primary #668FFF`…），`light-*` 与现项目一致不变 → 已确认**全局替换 dark-* token**。
- 内部组件直接写 `bg-dark-surface` 等静态类（无 `dark:` 前缀）→ 页面天然深色，固定深色与设计一致。
