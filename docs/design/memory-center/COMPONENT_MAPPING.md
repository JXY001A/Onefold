# 设计与业务映射（记忆中心）

> 分类：A=复用真实功能 / B=视觉改版 / C=UI 保留但无后端能力（按口径处理） / D=功能缺口 / E=mock 数据。
> 用户口径：无后端能力的动作 → 「敬请期待」；mock 数据仅字段微标「示例」；单条激活用 mock 停用状态。

## 3. Mock 数据规范（`lib/memoryMock.ts`）

- 确定性：以 item.id 做稳定哈希，同一 id 每次渲染得到相同 mock（引用次数 0–20、最近引用时间、1–3 条引用记录、是否停用约 20%）。
- 引用记录会话名取自固定示例池（与设计稿同风格的中文研究会话名）。
- 所有 mock 字段在 UI 上以 10px mono `示例` 微标标注；单条开关的 mock 行为同样带标。
- mock 不写入任何存储；刷新还原（用户已确认）。
