# 记忆中心施工方案（UI Implementation Plan）

> 用户已确认：① 目标是 /memory（按记忆中心稿）；② 暗色色板**全局替换**为宇宙蓝系；③ /memory **固定深色**；④ 分类 = 全部 + 6 大桶 + 「更多」展开细分；⑤ 无后端能力的动作 → 敬请期待；⑥ mock 数据仅字段微标「示例」；⑦ 单条激活用 mock 停用状态（内存态、刷新还原）。

## 2. 阶段划分

### 阶段 0：全局暗色换肤（token）
- 内容：`tailwind.config.js` dark-* 全量替换；重启 dev server 观察全站暗色。
- 允许修改：`tailwind.config.js`。
- 验收：`tsc` + `build` 通过；**暗色巡检**（/chat、/documents、/memory、/skills、/admin、/login 截图，无突兀反色/对比度问题，聊天页用户气泡自动切换为蓝色系为预期）；亮色主题巡检无变化；落地页 `/` 无变化。
- 回滚：还原 tailwind.config.js 单文件 diff。

### 阶段 1：页面骨架与数据层
- 内容：固定深色容器 + Header（静态部分）+ Stats 骨架 + 双栏骨架；`memory.ts` 类型追加；`memoryCategories.ts`（常量集中）；`memoryMock.ts`（确定性生成）；`useMemory` 派生统计与 mock 覆盖状态。
- 允许修改：阶段 1 对应文件。
- 验收：页面骨架与设计稿结构一致（空数据下的空态）；tsc/build；mock 函数输出对同一 id 稳定（脚本自测）。
- 回滚：按文件回退。

### 阶段 2：工具栏 + 列表
- 内容：搜索（内容/分类）、状态/类型筛选、三键排序（更新 updated_at / 创建 happened_at / 引用 mock）、分类 6 桶 +「更多」展开细分、列表卡全部交互（选中/单条 mock 开关/编辑入口/删除入口/空态）。
- 验收：各筛选组合结果正确（含"示例"微标展示规则）；1440 截图对比；窄屏单栏。
- 回滚：按文件回退。

### 阶段 3：详情 + 弹窗 + 全局开关联调
- 内容：详情面板（含引用记录 mock、来源 run_id 展示、空态）、编辑弹窗（真实 PATCH text 保存；分类/类型/激活只读）、删除/清空确认弹窗（真实 DELETE）、全局开关与关闭横幅（真实 PATCH settings）、新增/导出/查看来源对话 → 敬请期待 toast。
- 验收：编辑保存后列表/详情刷新一致；删除/清空后有 toast 且列表更新；开关关闭后横幅出现、列表降透明度；所有 mock 字段均有微标。
- 回滚：按文件回退。

### 阶段 4：整页回归与验收
- 内容：1440/1280/1024/390 视口截图与设计稿对比；键盘 Tab 走查；console 无错误；全站暗色巡检复核；`git diff` 范围核对。
- 验收：与设计稿布局/间距/颜色一致（除已登记的 mock/敬请期待/固定深色偏差）；既有记忆后端测试不回归（不改后端，跑基线即可）。
- 回滚：整体 revert 本批文件。

## 3. 视觉验收方法

- 设计侧：无头 Chrome 渲染设计稿 HTML（1280×1024）。
- 实现侧：dev server 真实页面（1280×1024 与 1440×1024）。
- 对比项：结构、尺寸、间距、字号、颜色、圆角、边框、图标、状态。
- 构建通过不代替视觉验收。

## 4. 已知偏差登记

1. /memory 固定深色（用户确认）；亮色主题下该页仍为深色卡片。
2. 单条停用状态与引用数据为 mock，UI 以「示例」微标标注；刷新还原。
3. 新增记忆/导出记忆/「查看来源对话」为敬请期待；编辑弹窗分类/类型/激活只读。
4. 记忆来源显示真实 run 短 id（后端无会话名），设计稿的会话名为 mock 素材。
5. 分类筛选为「6 桶归并 + 更多展开细分」（用户补充要求，设计稿仅有 6 类）。
6. 全局暗色换肤会改变全站暗色视觉（用户确认）。
