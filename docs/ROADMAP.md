# Onefold 个人 Agent 实验室路线图

> 定位：服务个人学习与实验，不对外公开。主线 **AI Agent 工程**，辅线 **AI 应用技术**；不做 AI 政策合规产品。
> 投入：约 25 小时/周（5h × 5 天）。原则：B（Agent 内核）为主、A（学习闭环）为辅；每周一个可演示增量。
> 约束：单人使用优先，不做多租户/社区/审核/计费；后端与数据库改造遵循现有规范（先方案、后施工）。

## 1. 北极星与指标

北极星：一个个人可用的 Agent 实验室——订阅前沿来源、生成可追溯报告、用 Skill 固化工作流、每轮决策可回放与评测，并把结论沉淀进记忆。

| 指标 | 目标 |
|---|---|
| 引用覆盖率 | 有检索资料的报告中，主要结论引用覆盖率 ≥ 90%（抽样人工核验） |
| Skill 复用 | 每周至少 2 个固定工作流由 Skill 驱动 |
| Trace 完整度 | 每轮包含模型、工具、耗时、token、上下文预算 |
| 评测可比 | ≥20 个固定任务，离线可跑，每次改动可对比 |

## 2. 12 周里程碑

| 周 | 阶段 | 交付物 | 验收 |
|---|---|---|---|
| W1 | 可信内核①引用 | 结构化引用链路（检索→上下文编号→模型标记→SSE→落库→UI 胶囊/来源列表） | 引用可定位原文；刷新后保留；离线测试覆盖 |
| W2 | 可信内核②Skill 运行时 | `SKILL.md` 导入、启用注入、`read_skill` 工具、导入 UI 放开 | 导入→启用→对话生效；错误码正确 |
| W3 | 可信内核③Trace+评测基线 | 每轮 Trace 落库（90 天、脱敏）、Trace 查看器、20 任务评测 | 可回放一轮决策；产出基线分数 |
| W4 | 学习闭环①信源 | RSS/arXiv/URL 订阅入库（inbox）、去重、主题打标 | 5 个源 24h 内入库且不重复 |
| W5 | 学习闭环②主题与笔记 | 主题空间、阅读状态（未读/在读/已掌握）、笔记 | 一条信源可推进到「已掌握」并留笔记 |
| W6 | 学习闭环③周报 | Skill 固化「每周前沿简报」：聚合+引用+笔记 | 生成可核验周报，引用达标 |
| W7 | 学习闭环收口 | 真实使用一周 + 体验修补 + 使用说明 | 连续 7 天使用无阻断 |
| W8 | Agent Lab①Trace 完整化 | 列表/详情/过滤、上下文预算、成本与延迟 | 能解释单轮慢/贵/选错工具 |
| W9 | Agent Lab②实验框架 | 模型/Prompt/工具集/检索策略 A/B 与对比报告 | 同一任务集完成一次 A/B |
| W10 | Agent Lab③注册表 | 工具注册、权限边界、Skill 真实字段增强 | 新工具/Skill 不改核心代码接入 |
| W11 | Agent Lab④记忆与压缩评测 | 记忆开/关、长对话压缩对比、错误样例集 | 产出可复现结论 |
| W12 | 多 Agent v0 | 检索者/核验者/撰写者协作（开关）、阶段复盘 | 与单 Agent 有量化差异 |

Q2 方向：多 Agent 调度、工具自动发现、应用案例（论文精读、技术雷达）；仍保持个人使用。

## 3. 技术默认（已确认）

- **引用**：复用 `retrieve()` 的 chunk 元数据；消息编号 `c1..cN`；模型标记 `[c1]`；SSE `citation` 事件（前端类型已预留）；消息表新增引用 JSON（迁移）。
- **Skill**：单文件 `SKILL.md`；admin/超管可导入；重名拒绝；默认停用；规格见 `SKILL_IMPORT_SPEC.md`。
- **Trace**：`traces` 表，字段含 turn/step/tool/latency/tokens/context_budget/error；只存 ID 与哈希，保留 90 天。
- **评测**：本地 YAML 任务 + 确定性断言为主，LLM 评审为辅；CI 只跑离线。
- **信源**：RSS/arXiv 优先，URL 手动收录；不做全站爬虫。
- **前端**：新增「实验室（Trace/评测/实验）」与「学习（Inbox/主题/笔记）」入口；现有五页不推倒。

## 4. 工作流与产出

每个 Phase：设计笔记（为什么）→ 代码 → 离线测试 → 真实截图/评测 → 实验结论（学到了什么）→ 下一阶段输入。

## 5. 风险与对策

1. 范围膨胀：A 的功能不得反向拖慢 B；超范围记录不做。
2. 引用失真：只允许引用真实检索块；模型标记需校验；无资料时不生成引用。
3. 提示词不守约：用明确编号协议 + 评测集监控合规率；不通过则回退「仅来源列表」。
4. 评测维护：任务集每月只增不减，报告留档。
5. 多 Agent 过早：W12 前不做调度器。
